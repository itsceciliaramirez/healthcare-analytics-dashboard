# Healthcare Analytics Platform

A full-stack healthcare analytics dashboard built using React, Node.js, Express, PostgreSQL, Neon, Render, and Vercel.

## Live Demo

[View Live Dashboard](https://healthcare-analytics-dashboard-peach.vercel.app)

## GitHub Repository

https://github.com/itsceciliaramirez/healthcare-analytics-platform

---

# Features

- Healthcare KPI dashboard
- Appointment analytics
- Patient funnel analysis
- Department performance tracking
- Appointment trend visualization
- Dark mode toggle
- Department filtering
- REST API integration
- Cloud database deployment

---
